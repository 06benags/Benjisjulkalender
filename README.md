# Julmysteriet – De 24 låsta luckorna 🎄

En mysig, svensk julkalender i escape-room-stil. Lös gåtor för att låsa upp nästa lucka, samla hemligheter och tänd julstjärnan.

## Kom igång lokalt
Öppna `index.html` i en modern webbläsare. Ingen byggprocess eller installation behövs.

## Publicera med GitHub Pages
1. Öppna repositoryts **Settings → Pages**.
2. Under **Build and deployment**, välj **Deploy from a branch**.
3. Välj branch **main** och mapp **/(root)**, klicka **Save**.
4. Vänta tills GitHub Pages publicerat webbplatsen. Adressen visas på samma sida.

## Funktioner
- Responsiv design för mobil och dator.
- 24 luckor med gåtor och ledtrådar som pekar ut nästa lucknummer.
- Sparar framsteg lokalt i webbläsaren.
- Hjälpknapp, tillgängliga dialoger och möjlighet att börja om.
- Ingen server, databas eller API-nyckel behövs.

Framsteg sparas i den aktuella webbläsaren på den aktuella enheten. Om webbläsardata rensas försvinner sparningen.
